# CareerCompass 개인정보처리방침 (초안)

이 문서는 초안이다. LLM 전송 범위가 비어 있어, 이를 채우기 전에는 공개하지 않는다. 전송 범위는 [BE #48](https://github.com/Team-CareerCompass/CareerCompass-BE/issues/48) 이 정한다. 선언과 실제가 다르면 스토어 정책 위반이므로, 서버가 실제로 무엇을 보내는지 확정된 뒤에 이 문서를 확정한다.

게시처와 절차는 [`privacy-policy-hosting.md`](privacy-policy-hosting.md) 에 정해 뒀다. FE 저장소의 GitHub Pages 에 이 파일 한 장을 페이지로 올리고, 그 주소를 Play Console 의 앱 콘텐츠 선언과 앱에 함께 건다.

시행일: 게시일에 맞춰 채운다.

## 1. 우리가 누구인가

CareerCompass 는 건국대학교 졸업 프로젝트로 만드는 앱이다. 팀 CamBridge(정일혁, 이준혁, 조영탁, 서성덕)가 개발하고 운영한다. 상업 서비스가 아니며, 프로젝트가 끝난 뒤의 운영 기간과 종료 방식은 아래 6항에 적는다.

## 2. 무엇을 모으는가

| 구분 | 항목 | 언제 |
|---|---|---|
| 계정 | 이메일, 이름, 소셜 로그인 제공자 식별자 | 카카오 또는 구글로 로그인할 때 |
| 프로필 | 학교, 전공, 학년, 희망 직무, 관심 태그 | 온보딩과 프로필 편집에서 직접 입력할 때 |
| 경험 | 경험 카드(활동명, 기간, 역할, 내용, 링크) | 직접 입력할 때 |
| 문서 | 과거 지원서 파일(PDF·DOCX·TXT)과 그 본문 | 직접 올릴 때. 선택 항목이다 |
| 지원서 | 생성하거나 저장한 자기소개서 본문과 버전 | 지원서를 만들고 저장할 때 |
| 활동 | 등록한 게시판, 읽은 공고, 북마크, 지원 이력 | 앱을 쓰는 동안 |
| 기기 | 알림 토큰 | 알림을 켤 때 |
| 진단 | 크래시 로그, 오류 발생 시각과 화면 | 앱이 오류를 만났을 때 |

앱은 연락처, 사진, 위치, 광고 식별자를 수집하지 않는다. 광고 SDK 를 넣지 않았고, 광고 식별자 권한은 앱 매니페스트에서 제거한다.

## 3. 무엇에 쓰는가

- 계정과 프로필: 로그인, 본인 확인, 적합도 분석의 기준
- 경험 카드와 과거 지원서: 공고 적합도 산출, 자기소개서 초안 생성, 문체 참고
- 활동: 피드 구성, 읽음 표시, 추천
- 알림 토큰: 새 공고, 마감 임박, 수집 오류 알림
- 진단: 오류 수정

수집한 정보를 광고나 마케팅에 쓰지 않는다. 판매하지 않는다.

## 4. 누구에게 넘어가는가

| 받는 곳 | 무엇이 | 왜 |
|---|---|---|
| LLM API 제공자 | (확정 전) | 공고 분석, 적합도 산출, 자기소개서 초안 생성 |
| Google Firebase (Crashlytics·Cloud Messaging) | 크래시 로그, 알림 토큰 | 오류 수정, 알림 발송 |
| Amazon Web Services | 위 2항의 저장 데이터 | 서버와 데이터베이스 운영 |

LLM 제공자에게 무엇을 보내는지는 서버가 정한다. 항목과 마스킹 범위가 확정되면 이 표를 채우고, 앱 안에서도 같은 내용을 보여 준다.

## 5. 어떻게 지키는가

- 앱과 서버 사이 통신은 HTTPS 로만 한다. 평문 HTTP 는 앱이 차단한다
- 로그인 토큰은 앱 전용 저장소에 두고 기기 백업에서 제외한다
- 로그아웃하면 기기의 토큰을 지운다

## 6. 얼마나 두는가

- 계정을 지우면 프로필, 경험 카드, 과거 지원서, 생성한 지원서를 함께 지운다
- 크래시 로그는 Firebase 의 보관 정책을 따른다
- 졸업 프로젝트 심사가 끝난 뒤의 서비스 유지 기간과 종료 절차는 [BE #54](https://github.com/Team-CareerCompass/CareerCompass-BE/issues/54) 에서 정한다. 서비스를 닫을 때는 최소 30일 전에 앱과 이 페이지로 알리고, 종료일에 저장된 데이터를 파기한다

## 7. 무엇을 요구할 수 있는가

열람, 정정, 삭제, 처리 정지를 요청할 수 있다. 앱의 설정에서 계정 삭제로 직접 지울 수 있고, 문의처로 요청해도 된다.
