# 분석 · 커리어 로드맵

하단 **분석 → 커리어 로드맵**에서 동기·합격 선배·내 성장 세 가지를 전환한다. 비교 대상을 바꾸면 새 데이터를 읽으며, 이전 대상의 늦은 응답이 현재 화면을 덮지 않는다. 로드맵의 뒤로 가기는 분석 홈으로 돌아온다.

동기·합격 선배 화면에는 비교한 사람 수와 각 지표의 내 값·평균을 함께 표시한다. 같은 지표의 두 막대는 같은 눈금을 쓴다. 서로 다른 지표(경험 수와 학점 등)끼리는 단위가 다르므로 막대 길이를 비교하지 않는다. 표본이 없거나 지표가 없으면 수치 대신 정보 부족 안내를 보인다. 최소 표본 수 정책은 서버가 결정한다.

내 성장은 현재 기록을 따로 보여 준다. API_SPEC §7에는 과거 기록의 시점·기간이 없으므로 `peerAvg`를 과거의 내 값으로 해석하거나 성장률을 만들지 않는다. 이전 시점 기록이 아직 제공되지 않는다는 안내를 함께 표시한다.

서버의 학기별 제안은 학기와 행동 문구로 표시한다. 프로필이 부족하면 **프로필 입력하기**로 이동하고, 돌아오면 다시 비교를 읽는다. 네트워크 실패는 빈 결과와 구분하고 재시도할 수 있다. 세션이 만료되면 로그인으로 돌아간다.

이 화면은 `GET /roadmap/compare?cohort=peer|senior|me_only`를 사용한다. 비교 지표의 종류·표본 수·평균·제안은 서버 응답을 그대로 사용하며, 없던 지표를 0으로 만들지 않는다. For You 추천은 #191 범위다.

## 내 강점 정리

분석 홈의 **내 강점 정리**에서 기본 정보·핵심 기술 스택·프로젝트·수상 이력·AI 한 줄 요약 중 포함할 정보를 고른다. Markdown·Notion·HTML·Plain 중 형식을 선택한 뒤 **미리보기 만들기**를 누른다. 생성 중에는 선택을 잠그고 중복 요청을 막는다. 선택을 바꾸면 이전 미리보기는 지워진다.

미리보기는 서버가 돌려준 본문 그대로다. HTML도 실행하거나 별도 웹페이지로 띄우지 않고 원문으로 표시한다. **클립보드에 복사**를 누른 뒤 사용할 앱에 붙여넣는다. 화면을 나가거나 앱이 재시작돼도 자동으로 복사하지 않는다. 복사가 실패하면 미리보기의 글을 길게 눌러 복사할 수 있다.

전달 방식을 클립보드로 정한 이유는 서버 응답이 파일이 아닌 `content` 문자열이고, 네 형식을 편집기에 붙여넣는 흐름에 공통으로 쓸 수 있기 때문이다. 저장소 권한이나 외부 앱 연동 권한을 새로 요구하지 않는다. 시스템의 클립보드 미리보기에서는 개인 정보가 노출되지 않도록 민감한 내용 표시를 적용한다.

경험 카드가 없으면 추가 경로를 안내하지만 기본 정보까지 막지 않는다. 실제로 내보낼 내용이 비어 있으면 빈 결과 안내를 보여 주고 복사를 막는다. 포함할 정보를 하나도 고르지 않으면 서버 요청을 보내지 않는다. 형식과 섹션 선택만 복원하고 본문·생성 중 상태·복사 요청은 저장하지 않는다.
