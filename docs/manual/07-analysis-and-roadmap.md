# 분석 · 커리어 로드맵

하단 **분석 → 커리어 로드맵**에서 동기·합격 선배·내 성장 세 가지를 전환한다. 비교 대상을 바꾸면 새 데이터를 읽으며, 이전 대상의 늦은 응답이 현재 화면을 덮지 않는다. 로드맵의 뒤로 가기는 분석 홈으로 돌아온다.

동기·합격 선배 화면에는 비교한 사람 수와 각 지표의 내 값·평균을 함께 표시한다. 같은 지표의 두 막대는 같은 눈금을 쓴다. 서로 다른 지표(경험 수와 학점 등)끼리는 단위가 다르므로 막대 길이를 비교하지 않는다. 표본이 없거나 지표가 없으면 수치 대신 정보 부족 안내를 보인다. 최소 표본 수 정책은 서버가 결정한다.

내 성장은 현재 기록을 따로 보여 준다. API_SPEC §7에는 과거 기록의 시점·기간이 없으므로 `peerAvg`를 과거의 내 값으로 해석하거나 성장률을 만들지 않는다. 이전 시점 기록이 아직 제공되지 않는다는 안내를 함께 표시한다.

서버의 학기별 제안은 학기와 행동 문구로 표시한다. 프로필이 부족하면 **프로필 입력하기**로 이동하고, 돌아오면 다시 비교를 읽는다. 네트워크 실패는 빈 결과와 구분하고 재시도할 수 있다. 세션이 만료되면 로그인으로 돌아간다.

이 화면은 `GET /roadmap/compare?cohort=peer|senior|me_only`를 사용한다. 비교 지표의 종류·표본 수·평균·제안은 서버 응답을 그대로 사용하며, 없던 지표를 0으로 만들지 않는다. For You 추천과 강점 Export는 각각 #191·#193 범위다.
