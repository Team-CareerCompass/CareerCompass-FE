# CareerCompass 사용자 매뉴얼

앱을 처음 여는 사람이 가입부터 공고 상세까지 혼자 갈 수 있게 쓴 안내다.

**이 매뉴얼은 앱에 실제로 있는 것만 적는다.** 화면 문구는 저장소의 문자열 리소스와 Composable 에서 그대로 옮겼고, 아직 만들지 않은 화면과 버튼은 여기에도 없다.

- 기준: `develop` `a6cb50a`
- 캡처는 아직 없다. 실서버가 붙은 뒤에 찍어야 화면에 실제 데이터가 담기므로, 지금은 들어갈 자리만 `> 캡처 자리:` 줄로 표시해 두었다.

## 차례

| 부 | 문서 | 무엇을 다루는가 |
| --- | --- | --- |
| 1부 | [가입과 온보딩](01-signup-and-onboarding.md) | 소셜 로그인, 지문 로그인, 온보딩 4단계, 완료 화면 |
| 2부 | [게시판](02-boards.md) | URL 등록, 구조 분석 결과, 이름·유형·수집 주기, 내 게시판 목록 |
| 3부 | [피드와 적합도](03-feed-and-suitability.md) | 검색·필터·정렬·북마크, 적합도 4축, 공고 상세와 원문 보기 |
| 5부 | [마이 탭](05-my-tab.md) | 마이 홈, 프로필 편집, 경험 카드, 과거 지원서, 지문 로그인·화면 테마·로그아웃 |

읽는 순서는 위에서 아래다. 1부를 마치면 계정이 생기고, 2부를 마치면 공고가 들어오기 시작하고, 3부는 들어온 공고를 고르는 법이다. **게시판을 하나도 등록하지 않으면 피드에 아무것도 쌓이지 않는다.** 앱이 스스로 공고를 찾아 오지 않는다는 것이 처음 쓰는 사람이 가장 많이 막히는 자리라, 2부를 건너뛰지 않기를 권한다. 5부는 순서에 매이지 않는다. 온보딩에서 넣은 것을 나중에 고칠 때 편다.

## 아직 쓰지 않은 부

지원서(4부)는 #185~#187 이, 알림(6부)은 #195~#196 이 머지된 뒤에 쓴다. 지금 하단 탭의 「분석」·「지원서」, 피드 헤더의 알림 버튼, 마이 홈의 「알림 설정」, 과거 지원서의 「지원서 추가」를 누르면 준비 중이라는 자리표시자가 나온다. 매뉴얼 전체의 범위는 이슈 #268 에 있고, 1~3부는 #289 로, 5부는 #333 으로 갈라 먼저 썼다.

## 이 매뉴얼이 값을 적지 않는 것

- 적합도 축마다 붙는 비율은 서버가 공고마다 내려 준다. 앱이 들고 있는 고정값이 아니라서 여기에 숫자를 적지 않는다.
- 수집이 몇 번 실패하면 자동으로 멈추는지 같은 판정도 서버가 한다. 앱은 그 결과를 배지와 안내로 보여 줄 뿐이라 그 값도 적지 않는다.
- 프로필 완성도 퍼센트의 산식, 프로필을 고친 뒤 적합도가 다시 계산되는 시점, 과거 지원서를 항목으로 나누고 분류하는 결과도 서버 몫이다. 5부는 그 자리에 캡처 자리만 둔다.
