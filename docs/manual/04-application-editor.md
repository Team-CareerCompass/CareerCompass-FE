# 지원서 초안과 편집

공고 상세에서 「지원서 초안 작성하기」를 눌러 시작한다. 인식된 문항을 확인하고 필요하면 고친 뒤 「초안 작성 시작」을 누른다. 문항이 인식되지 않았으면 직접 입력할 수 있다.

## 생성 중인 답 확인하기

항목이 완성되는 대로 답이 표시된다. 실패한 문항은 「이 항목 다시 시도」로 다시 생성한다. 연결이 끊기면 이미 받은 답을 유지하고 다시 확인할 수 있다.

「이 항목 편집」을 누르면 답변 입력창이 열린다. 위쪽 문항 탭을 좌우로 밀어 다른 문항으로 이동한다. 「다음 문항」으로도 이동할 수 있다. 줄바꿈과 붙여넣기를 지원하며 문항을 오가도 입력한 글은 남는다.

## 글자 수와 입력 보관

입력창 아래에 현재 글자 수와 문항의 최대 글자 수가 표시된다. 최대치를 넘으면 경고가 표시되지만 글을 자르지 않는다. 최종 저장할 때 다시 확인한다.

작성 화면이 유지되는 동안에는 화면 회전이나 다른 앱을 다녀온 뒤에도 수동 입력을 복원한다. 모든 문항의 임시 입력을 합해 10만 자를 넘는 붙여넣기는 반영하지 않고 안내한다. 이 경우 기존 글은 그대로 남는다.

## 임시 저장과 최종 저장

편집 화면을 보고 있으면 30초마다 수정한 내용을 임시 저장한다. 글자 수를 넘은 초안도 입력한 그대로 보관하며, 성공한 뒤 「마지막 임시 저장」 시각이 표시된다. 탭을 누르는 동작 자체가 저장을 실행하지는 않는다.

저장이 실패하면 이유와 「다시 저장」 버튼이 표시된다. 3회 연속 실패하면 자동 저장을 멈춘다. 연결 등 안내된 문제를 해결한 뒤 「다시 저장」을 누른다. 실패해도 화면에 입력한 내용은 유지된다.

생성이 끝나면 「최종 저장」으로 지원서를 확정한다. 실패한 항목은 먼저 직접 작성하거나 다시 생성한다. 글자 수를 넘긴 항목이 있으면 「계속 편집」 또는 「그대로 저장」을 고른다. 「그대로 저장」은 글을 자르지 않고 저장한다. 실제로 제출할 기관의 양식에서는 초과한 글이 잘릴 수 있으므로 제출 전에 확인한다.

최종 저장 중에는 편집과 뒤로가기가 잠시 잠긴다. 「지원서를 저장했어요」가 표시되면 지원 이력도 생성된 상태다. 「작성 화면 닫기」로 원래 공고에 돌아간다.

> 캡처 자리: 생성 중 일부 답을 받은 화면, 문항별 편집 화면, 글자 수 초과 확인 창, 저장 완료 화면.

재생성 옵션·버전 목록과 지원 이력 목록 화면은 각각 #186·#188의 별도 범위다.
